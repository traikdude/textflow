## 🛠️ Development Setup

### Prerequisites
- Node.js ≥14.x
- Clasp CLI: `npm install -g @google/clasp`
- Git

### Local Development
```bash
# Clone this repository
git clone https://github.com/traikdude/textflow.git
cd textflow

# Login to Clasp
clasp login

# Pull latest from Apps Script
clasp pull

# Push changes to Apps Script
clasp push
```
